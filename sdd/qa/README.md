# Quality Assurance

This directory is reserved for QA planning and project verification records.

Use it for test strategies, test plans, manual test cases, acceptance test mappings, test data guidance, defect summaries, and release or verification reports. Link cases to requirements and acceptance criteria so coverage is reviewable.

Keep automated tests alongside the code they exercise when that matches the selected build tools, and document how to run the overall checks here when those tools are established. Use repeatable test data and avoid production systems or real personal data. No test plans or reports are included in this foundation.
