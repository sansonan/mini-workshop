# Backend

This directory is reserved for the Java 21 and Spring Boot application.

When the backend is initialized, document its chosen build tool and framework versions, module structure, local run command, required configuration, service address, and relevant checks here. Keep implementation aligned with the approved requirements, architecture, and API contracts in `docs/`.

Keep credentials outside source control. Add or update automated tests for specified behavior and coordinate API or persistence changes with `frontend/`, `database/`, and `qa/` as needed. No backend source code or build files are included in this foundation.
