# Agent Roles and Workflows

Use this directory for project-specific AI agent role definitions and collaboration workflows.

Role documents may describe responsibilities, required inputs, expected outputs, boundaries, and handoff points for work such as requirements analysis, architecture review, backend implementation, frontend implementation, database design, and QA. Keep reusable task procedures in `.agents/skills/` and project-wide rules in `AGENTS.md`.

Agent guidance must defer to approved specifications, avoid duplicating conflicting instructions, and make human review points explicit where a decision changes scope, behavior, or architecture. No role definitions are included yet; add them when the project needs them.
