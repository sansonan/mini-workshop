# Frontend

This directory is reserved for the React application.

When the frontend is initialized, document the selected React tooling and versions, package manager, install and run commands, local address, environment configuration, and relevant checks here. Implement screens and user flows from approved requirements and acceptance criteria, and use the API contracts documented in `docs/`.

Follow the project's established formatting and component conventions. Keep configuration and secrets out of source control, and include accessible behavior and appropriate loading, empty, success, and error states. No frontend source code or package manifest is included in this foundation.
